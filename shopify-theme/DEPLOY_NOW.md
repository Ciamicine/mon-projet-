# 🚀 DÉPLOYER MAINTENANT EN 3 CLICS

## Méthode 1: Via Shopify Admin (Plus Simple ✅)

1. Va sur: https://admin.shopify.com/
2. Shopify Admin → Online Store → Themes
3. "Upload theme" → Sélectionne le dossier `shopify-theme/`
4. Click "Upload theme"
5. ✨ DONE! Ton theme est là!

## Méthode 2: Avec Shopify CLI (Terminal)

```bash
cd shopify-theme/

# Authenticate
shopify auth login --shop ptitdetour.myshopify.com

# Test locally
shopify theme dev

# Deploy live!
shopify theme push --live
```
