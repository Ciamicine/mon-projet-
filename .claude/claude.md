# Claude Code Configuration

## 21st.dev Skills

This project is configured with the following 21st.dev skills for UI development:

- **21st-ai**: Generate and iterate on UI with 21st AI from the terminal
- **21st-cli-use**: Search, install and pull code from the 21st.dev catalog
- **21st-registry**: Publish your own work to 21st.dev and manage it
- **21st-design-sync**: Publish your project's design as a shareable 21st theme
- **21st-ui-build**: Build or substantially change production UI
- **21st-ui-explore**: Explore and compare multiple UI directions
- **21st-ui-review**: Review existing UI against design context and standards

## Dependencies

- `@anthropic-ai/sdk`: Anthropic SDK for Claude API integration

## Getting Started

```bash
npm install
```

Use the 21st skills to generate, explore, and manage UI components.
